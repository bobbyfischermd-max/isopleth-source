Plain-text fetch (no ZIP)
=========================

This repository is the Isopleth source archive, one file per path.
A file-fetch tool can read any text file directly. Do not use the ZIP.

Repository:
https://github.com/bobbyfischermd-max/isopleth-source

Raw file URL pattern:
https://raw.githubusercontent.com/bobbyfischermd-max/isopleth-source/main/<path>

Start here:

The preview OAuth client secret is redacted in src/lib/auth/preview.ts.
